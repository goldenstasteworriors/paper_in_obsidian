# LLaVA

LLaVA 是一类使用视觉编码器、投影层和大语言模型构建的指令跟随视觉语言模型。

## 在论文中的作用

- [[PaliGemma]] 将 LLaVA 作为偏 instruction-following 数据和聊天接口的代表方法。
- PaliGemma 与其不同，重点是训练可迁移的 base VLM，而不是直接优化聊天体验。

## 代表工作

- [[PaliGemma]]: 对比 instruction-tuned VLM 与 transfer-oriented base VLM。
