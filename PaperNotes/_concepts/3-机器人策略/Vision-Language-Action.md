# Vision-Language-Action

`Vision-Language-Action` 常写作 `VLA`，指把视觉观测、语言指令和动作生成统一到一个模型中的机器人策略范式。

## 为什么重要

- 它试图用统一表示处理 perception、instruction following 和 control。
- 当前很多 manipulation 和 humanoid 论文都在讨论 VLA 的泛化、延迟和 embodiment gap。
- 在 [[Cross-Hand]]、[[FutureVLA]]、[[DepthCache]] 这类工作里，VLA 是直接讨论对象。
