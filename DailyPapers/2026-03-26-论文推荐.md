## Humanoid / Teleoperation

### 1. MIRROR: Visual Motion Imitation via Real-time Retargeting and Teleoperation with Parallel Differential Inverse Kinematics
- **作者**: Junheng Li, Lizhi Yang, Aaron D. Ames
- **机构**: California Institute of Technology
- **链接**: [arXiv](https://arxiv.org/abs/2603.23995v1) | [PDF](https://arxiv.org/pdf/2603.23995v1)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[MIRROR]]

![](https://arxiv.org/html/2603.23995v1/x1.png)

- **核心方法**: 这篇的关键不是“又做了个 teleop pipeline”，而是把视觉骨架、任务空间 continuation、并行 differential IK 和碰撞安全约束串成一个能跑在真机上的闭环。输入是 ZED 2i 提取的 3D skeleton 关键点，先经过 confidence gating、jump rejection 和 multi-body rejection 做稳态过滤，再转成 humanoid 任务空间目标。控制端不是直接解一个 IK，而是并行求一族不同 continuation 系数的 [[Differential Inverse Kinematics]] QP，再用基于 [[Control Barrier Function]] 的碰撞约束和 Lyapunov progress certificate 选出既安全又能真正朝最终目标下降的那个更新。
- **对比方法/Baselines**: 主要对比 global IK、monolithic QP、distributed QP、parallel monolithic QP 和去掉 progress certificate 的并行版本。它借了 [[Control Barrier Function]]、QP 和 continuation 的经典工具，但关键区别在于不再假装单个 differential IK 解会自己走出 basin。
- **借鉴意义**: 对 humanoid teleoperation、motion retargeting、whole-body tracking reference generation 都是直击痛点。你要做 cross-embodiment imitation 或 whole-body teleop，这篇最大的价值是告诉你“实时、安全、别卡死”不是三个分开的工程问题。
- **锐评**: 这篇有真东西，因为它终于承认 differential IK 的主要问题不是不够快，而是太容易在约束边界、奇异位形和关节极限附近装死。Table I 里 global IK 虽然误差最低，但 176 ms 的求解时间对实时 teleop 基本等于判死刑；MIRROR 把求解时间压到约 4 ms，同时把 self-collision 和 stagnation 大幅拉下来，这个 trade-off 很硬。硬伤也不难找: 现在主打的是 upper-body teleop，真正 full-body loco-manipulation 还没展开，最后执行质量也仍然依赖下游 [[Whole-Body Controller]]。🔥
- **关联笔记**: [[Whole-Body Controller]] — MIRROR 负责把人动作安全地变成关节目标，但最终闭环执行还是要靠 WBC 扛住平衡和接触。  
[[Model Predictive Control]] — 论文把并行优化拿来做 IK coverage，而不是直接拿 MPC 当借口把实时性拖死。

### 2. SafeFlow: Real-Time Text-Driven Humanoid Whole-Body Control via Physics-Guided Rectified Flow and Selective Safety Gating
- **作者**: Hanbyel Cho, Sang-Hun Kim, Jeonguk Kang, Donghan Koo
- **机构**: Samsung Electronics
- **链接**: [arXiv](https://arxiv.org/abs/2603.23983v1) | [PDF](https://arxiv.org/pdf/2603.23983v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.23983v1/x1.png)

- **核心方法**: SafeFlow 做的是 text-driven humanoid control，但它至少没再假装“文生动作”天然能上真机。高层在 VAE latent 里用 physics-guided rectified flow 生成 whole-body motion trajectory，并用 reflow 减少函数评估次数来压推理延迟。外面再套一个三阶段 safety gate: 先用 Mahalanobis score 做语义 OOD 过滤，再看 directional sensitivity discrepancy 去拦不稳定生成，最后再用关节/速度等硬约束做物理兜底。
- **对比方法/Baselines**: 核心对手是纯 kinematics-only 的 text-driven motion generator。它借了 rectified flow 和 safety filtering，但区别在于把“能不能执行”前置成优化目标，而不是最后把坏动作扔给 tracking controller 擦屁股。
- **借鉴意义**: 如果你关心 humanoid instruction following、language-to-motion 和安全部署，这篇值得看。尤其是 OOD prompt 过滤这层，很适合以后给 teleop / policy 接自然语言接口时做第一道闸。
- **锐评**: 这篇比一堆“text-to-humanoid demo 很丝滑”的论文清醒，因为它知道生成得像不等于机器人能跟。问题也同样明显: 它的主问题还是文本驱动动作生成，不是复杂接触、双臂协同或 whole-body interaction；安全门再细，也不能替代真正的任务级规划和接触建模。👀
- **关联笔记**: [[Whole-Body Controller]] — SafeFlow 的高层生成再漂亮，最后还是要靠底层控制去消化。  
[[Reinforcement Learning]] — 它的安全性不是纯 RL 学出来的，而是显式门控和约束在兜底。
- 💡 **想精读？** 运行：`读一下 SafeFlow: Real-Time Text-Driven Humanoid Whole-Body Control via Physics-Guided Rectified Flow and Selective Safety Gating`

### 3. PCHC: Enabling Preference Conditioned Humanoid Control via Multi-Objective Reinforcement Learning
- **作者**: Huanyu Li 等
- **机构**: Harbin Institute of Technology, University of Science and Technology of China, ShanghaiTech University
- **链接**: [arXiv](https://arxiv.org/abs/2603.24047v1) | [PDF](https://arxiv.org/pdf/2603.24047v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.24047v1/x1.png)

- **核心方法**: PCHC 想解决的是 humanoid control 里那个长期装看不见的问题: 速度、能耗、稳定性这些目标本来就是互相打架的，硬塞固定权重只会得到一个谁都不满意的折中策略。它用 [[Reinforcement Learning]] 里的 multi-objective formulation 做 preference-conditioned policy，让单个策略根据偏好向量切换行为。关键实现是用 Beta distribution based alignment 去调制 MoE 模块，把 preference 直接嵌进策略行为，而不是多训一堆 policy 去逼近 Pareto front。
- **对比方法/Baselines**: 对比的是固定加权的 humanoid RL 和需要多策略近似 Pareto front 的 MORL 方案。它的区别不在于又堆了个 backbone，而是把 preference 当成一等输入。
- **借鉴意义**: 对 fall recovery、locomotion，甚至以后 whole-body manipulation 里“速度优先还是稳定优先”的在线切换都很有启发。你如果想让 humanoid policy 在不同部署约束下切换风格，这篇比只会调 reward weight 的做法成熟得多。
- **锐评**: 这篇方向很对，因为真实机器人部署从来不是单目标优化。单策略覆盖多偏好也确实比训一排 policy 更像能用的系统。问题在于它目前验证任务还是偏 locomotion / recovery，离更复杂的 loco-manipulation 和 interaction 还差一截；如果状态分布再乱一点，这种 preference alignment 会不会塌，摘要还没给出硬证据。👀
- **关联笔记**: [[Reinforcement Learning]] — 这篇本质是在重写 humanoid RL 里的 reward 组织方式。  
[[Whole-Body Controller]] — 偏好条件最终会映射到控制风格差异，WBC 仍然是执行层关键。
- 💡 **想精读？** 运行：`读一下 PCHC: Enabling Preference Conditioned Humanoid Control via Multi-Objective Reinforcement Learning`

### 4. TAG: Target-Agnostic Guidance for Stable Object-Centric Inference in Vision-Language-Action Models
- **作者**: Jiaying Zhou, Zhihao Zhan, Ruifeng Zhai, Qinhan Lyu, Hao Liu, Keze Wang, Liang Lin, Guangrun Wang
- **机构**: Sun Yat-sen University, X-Era AI Lab
- **链接**: [arXiv](https://arxiv.org/abs/2603.24584v1) | [PDF](https://arxiv.org/pdf/2603.24584v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.24584v1/x1.png)

- **核心方法**: TAG 抓得很准，VLA 在 clutter scene 里经常不是“不会抓”，而是“抓到了差不多但不是那个实例”。它借 classifier-free guidance 的思路，在 inference 时同时看原始观测和 object-erased 观测，用两者预测差值做 residual steering，显式增强目标实例证据的权重。整个方法不改 backbone，几乎就是在推理阶段加一个 object-centric guidance。
- **对比方法/Baselines**: 主要对比原始 VLA policy 在 LIBERO、LIBERO-Plus、VLABench 里的表现。它明显是沿着 [[OpenVLA]] 这类路线修 inference stability，而不是重训一个全新 policy。
- **借鉴意义**: 对 clutter manipulation、目标实例对齐、VLA 稳定抓取都很实用。你如果觉得很多 VLA failure 并不是规划不行，而是 grounding 老偏半个杯子口，这篇就是对症修补。
- **锐评**: 这工作最讨喜的地方是务实。它不吹“通用 world understanding”，只修一个真实得不能再真实的 failure mode。短板也一样明显: 它修的是 instance-level grounding，不是长时序记忆、接触建模或者 action competence 本身；object erasing 做得不好时，guidance 也可能把噪声一并放大。👀
- **关联笔记**: [[OpenVLA]] — TAG 更像给现有 VLA 打一个 object-centric 补丁。  
[[Vision-Language-Action]] — 它提醒你 VLA 的一大坑不是生成不了动作，而是对错了对象。
- 💡 **想精读？** 运行：`读一下 TAG: Target-Agnostic Guidance for Stable Object-Centric Inference in Vision-Language-Action Models`

### 5. 3D-Mix for VLA: A Plug-and-Play Module for Integrating VGGT-based 3D Information into Vision-Language-Action Models
- **作者**: Bin Yu, Shijie Lian 等
- **机构**: HIT, HUST, HKUST(GZ), DeepCybo 等
- **链接**: [arXiv](https://arxiv.org/abs/2603.24393v1) | [PDF](https://arxiv.org/pdf/2603.24393v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.24393v1/x1.png)

- **核心方法**: 这篇最值钱的不是“又给 VLA 加了个 3D 模块”，而是先把 9 种 VGGT 融合方案系统比了一遍，再发现 semantic-conditioned gated fusion 最靠谱，最后把它封成 `3D-Mix` 这个 plug-and-play 模块。输入还是原有 2D 语义和 VLA observation，但额外注入 VGGT 的 3D 几何特征，由 gating 去按任务上下文平衡 2D semantics 和 3D geometry。它能直接插到 GR00T-style 和 π-style 架构里，不改原 MLLM 和 action expert。
- **对比方法/Baselines**: 对比的是九种不同的 3D 融合方式，以及多个 2B-8B 的 MLLM/VLA 变体。它借了 VGGT，但贡献在于给“3D 信息到底怎么混进 VLA”这件事一个系统答案。
- **借鉴意义**: 对 VLA 空间智能、OOD 操作鲁棒性和跨架构复用都很有用。你如果现在怀疑 VLA 的 2D prior 根本不够做真实 manipulation，这篇是比较像样的工程答案。
- **锐评**: 这类工作乍看没那么 flashy，但比很多只会喊“加 3D 会更强”的文章靠谱，因为它真的把融合 design space 扫了一遍。平均 +7% 的 OOD 提升也不是闹着玩的。问题在于它本质还是外挂式增强，3D backbone 成本、时延和部署复杂度都还在；如果后端 action policy 本身不行，几何再强也救不了全部。👀
- **关联笔记**: [[Vision-Language-Action]] — 3D-Mix 针对的是 VLA 长期缺的空间几何。  
[[OpenVLA]] — 这篇最像给 OpenVLA 一类架构补上真实 3D 感知。
- 💡 **想精读？** 运行：`读一下 3D-Mix for VLA: A Plug-and-Play Module for Integrating VGGT-based 3D Information into Vision-Language-Action Models`

### 6. VTAM: Video-Tactile-Action Models for Complex Physical Interaction Beyond VLAs
- **作者**: Yuan Haoran, Yi Weigang, Zhang Zhenyu, Chen Wendi, Mo Yuchen, Yin Jiashi, Li Xinzhuo, Zeng Xiangyu, Wen Chuan, Lu Cewu, Driggs-Campbell Katherine, Lourentzou Ismini
- **机构**: Shanghai Jiao Tong University, Stanford University, University of Illinois Urbana-Champaign
- **链接**: [arXiv](https://arxiv.org/abs/2603.23481v1) | [PDF](https://arxiv.org/pdf/2603.23481v1)
- **来源**: 📄 arXiv 关键词检索

> ⏪ **再推提醒**：这篇在 2026-03-25 推荐过

- **核心方法**: VTAM 的立场还是对的: 纯视频 world model 在 contact-rich 操作里经常不是看不见，而是根本感觉不到接触状态。作者在预训练 video transformer 上加 tactile stream，用轻量 modality transfer finetuning 做跨模态表示学习，再用 tactile regularization loss 抑制视觉模态独大，让 action model 在接触切换和力调制上别继续失明。
- **对比方法/Baselines**: 主要对着纯视觉 VAM/VLA 以及 `pi 0.5` 一类 baseline。它不是另起炉灶训一个巨大新模型，而是直接在现有视频动作模型上插触觉。
- **借鉴意义**: 对 contact-rich manipulation、触觉 grounding、human-object interaction 都有实际参考价值。你如果后面要做 whole-body interaction 或灵巧手接触，这篇就是“为什么光看不够”的证据。
- **锐评**: 这篇昨天推过，今天还值得挂着，因为它碰的是 VLA/VAM 最真实的短板之一。问题仍然没变: 这更像 proof-of-need，而不是已经闭环完成的通用 tactile world model。能把视觉霸权打下来是第一步，离大规模可泛化操作还有一段。👀
- **关联笔记**: [[Vision-Language-Action]] — VTAM 是在给纯视觉 action model 补物理观测通道。  
[[AnyTouch]] — 都在问触觉信息到底该怎么真正进控制链路。
- 💡 **想精读？** 运行：`读一下 VTAM: Video-Tactile-Action Models for Complex Physical Interaction Beyond VLAs`

### 7. Chameleon: Episodic Memory for Long-Horizon Robotic Manipulation
- **作者**: Xinying Guo, Chenxi Jiang, Hyun Bin Kim, Ying Sun, Yang Xiao, Yuhang Han, Jianfei Yang
- **机构**: Nanyang Technological University, A*STAR, National University of Singapore
- **链接**: [arXiv](https://arxiv.org/abs/2603.24576v1) | [PDF](https://arxiv.org/pdf/2603.24576v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.24576v1/x1.png)

- **核心方法**: Chameleon 把“机器人也需要 episodic memory”这件事从口号变成了 geometry-grounded memory stack。它不是只存语义摘要，而是把多模态 token 按几何上下文写进可微记忆里，尽量保留那些能区分相似观察但不同历史的细粒度线索。作者还配了 `Camo-Dataset`，专门覆盖 perceptual aliasing 下的 episodic recall、spatial tracking 和 sequential manipulation。
- **对比方法/Baselines**: 主要对比基于语义压缩和 similarity retrieval 的 memory 方案。它的区别在于不再默认“像就够了”，而是强调对决策真正有用的几何细节。
- **借鉴意义**: 对 long-horizon manipulation、遮挡恢复、状态歧义消解很有帮助。你如果后面做 interaction 或 teleop 辅助，这类记忆机制比一味堆 context length 实在。
- **锐评**: 这篇值得看，因为它抓到了 embodied memory 里一个被 LLM 风格总结法拖歪的问题: 很多时候你缺的不是更会概括，而是别把关键几何线索概括没了。短板是任务规模和平台范围目前还偏窄，离真正复杂场景下的通用 episodic memory 还有距离。👀
- **关联笔记**: [[Vision-Language-Action]] — Chameleon 其实是在补很多 action model 的长时程观测缺口。  
[[Affordance]] — 记忆如果不能保留几何和可操作性线索，就很难真正服务 manipulation。
- 💡 **想精读？** 运行：`读一下 Chameleon: Episodic Memory for Long-Horizon Robotic Manipulation`

### 8. Knowledge-Guided Manipulation Using Multi-Task Reinforcement Learning
- **作者**: Aditya Narendra 等
- **机构**: MBZUAI, MIRAI, Innopolis University
- **链接**: [arXiv](https://arxiv.org/abs/2603.24083v1) | [PDF](https://arxiv.org/pdf/2603.24083v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.24083v1/assets/misc/RL_pipeline.jpg)

- **核心方法**: 这篇把知识图谱往控制里硬接，而不是继续把 scene graph 当可视化摆设。它提出 KG-M3PO，用在线 3D scene graph 把 open-vocabulary detection 落成带空间、包含关系和 affordance 边的 metric relational representation，再用图神经编码器和视觉/本体/语言观测一起训进多任务 RL policy。换句话说，它试图让 policy 真拿结构化世界知识来做动作选择。
- **对比方法/Baselines**: 对比的是不带知识图的 manipulation RL baseline。它借了 scene graph 和 multi-task RL，但区别在于把关系表示直接放进 control loop，而不是做外挂 planner。
- **借鉴意义**: 对 occlusion、distractor、layout shift 下的 manipulation 有参考价值。你如果关心 open-vocabulary perception 如何别停在 detector 层，这篇算一个还比较硬的尝试。
- **锐评**: 这篇的优点是终于不再把 knowledge graph 当 PPT 装饰，而是真的让它参与策略输入。问题也很直接: 这种 relational state 构建对感知质量依赖极强，感知一旦漂，图再漂亮也会把 policy 一起带偏；摘要里也没看到它对 real-world embodiment gap 给出很强证据。👀
- **关联笔记**: [[Affordance]] — 论文把 affordance 当图里的动态关系来维护，而不是一句模糊语义。  
[[Reinforcement Learning]] — 最终它还是靠 RL 把关系表示变成控制行为。
- 💡 **想精读？** 运行：`读一下 Knowledge-Guided Manipulation Using Multi-Task Reinforcement Learning`

### 9. Event-Driven Proactive Assistive Manipulation with Grounded Vision-Language Planning
- **作者**: Fengkai Liu 等
- **机构**: The University of Osaka, Nanyang Technological University, The University of Tokyo
- **链接**: [arXiv](https://arxiv.org/abs/2603.23950v1) | [PDF](https://arxiv.org/pdf/2603.23950v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.23950v1/x1.png)

- **核心方法**: 这篇最合理的地方是把 assistive manipulation 从“等用户发命令”改成“看见状态变化就主动补位”。它用 event monitor 跟踪人和物体交互导致的 workspace state transition，在事件结束时抓取稳定的 pre/post snapshot，再让 planner 根据状态变化反推出任务目标，并判断该不该介入。如果介入，就只在离散 action primitive 和 object ID 空间里生成可执行、可验证的辅助动作。
- **对比方法/Baselines**: 对比的是 request-driven 的协作式 manipulation。它明显更结构化，也更注重 planner 输出可落到执行接口上。
- **借鉴意义**: 对 human-robot collaboration、assistive manipulation、shared autonomy 很有启发。你如果关心机器人能不能从人类行为里读懂“下一步该帮什么”，这篇至少给了一个干净的事件驱动建模框架。
- **锐评**: 这工作难得没有把“proactive”说成读心术，而是老老实实地靠 pre/post state evidence 做推断，方向对。问题在于它目前还是 number-block 桌面协作这种强结构环境，动作空间也被 primitives 和 object IDs 限得很死；想扩到开放场景，感知噪声和事件分割都会立刻变成麻烦。👀
- **关联笔记**: [[Affordance]] — 事件触发的主动协助，本质上是在识别新的可帮助 affordance。  
[[Vision-Language-Action]] — 它更像把 VLM/VLA 用在任务级意图判断，而不是直接端到端控全身。
- 💡 **想精读？** 运行：`读一下 Event-Driven Proactive Assistive Manipulation with Grounded Vision-Language Planning`

## 被排除的论文

- `MiroThinker`、`Memento-Skills`、`MetaClaw`、`SpecEyes`：agent 热词再响，和 humanoid / manipulation 主线基本无关。
- `WildWorld`、`Attend Before Attention`、`Manifold-Aware Exploration for RL in Video Generation`：视频理解和生成很热，但离机器人闭环控制还隔着一层厚墙。
- `CoordLight`、`Bridging the Evaluation Gap`、`Learning-guided Prioritized Planning for Lifelong MAPF`：偏交通控制、多目标搜索和多智能体路径规划，不是今天这条主线。
- `GameplayQA`、`Tutor-Student Reinforcement Learning`：一个是 3D 虚拟视频理解 benchmark，一个是 deepfake detection，和 robotics 没什么关系。
- `Quadrature Oscillation System for Coordinated Motion in Crawling Origami Robot`：题目有机器人，但跟 humanoid / teleop / VLA 主线不在一个战场。
- `Off-Policy Safe Reinforcement Learning with Constrained Optimistic Exploration`：safe RL 方法学本身有价值，但今天这批里有更贴近 humanoid 和 manipulation 的东西，不需要它来抢位。

## 收尾

今天最该精读的是 `MIRROR`，因为它解决的是 humanoid teleoperation 里最脏也最真实的那层问题: 不是“动作看起来像不像人”，而是“约束一多时 IK 会不会卡死、撞上自己、还要不要实时”。第二梯队里，`TAG`、`3D-Mix`、`VTAM` 和 `Chameleon` 分别对应 VLA 的实例对齐、3D 感知、触觉缺口和长时记忆，这几篇比再看一个 agent 榜单有用得多。
