## Humanoid / HOI

### 1. InterReal: A Unified Physics-Based Imitation Framework for Learning Human-Object Interaction Skills
- **作者**: Dayang Liang 等
- **机构**: Xiamen University / Zhejiang University / ShanghaiTech University / TeleAI
- **链接**: [arXiv](http://arxiv.org/abs/2603.07516v1) | [PDF](https://arxiv.org/pdf/2603.07516v1)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[InterReal]]
- **核心方法**: 用 physics-based imitation 学 humanoid 的 [[HOI]] 技能，在 inner loop 用 [[PPO]] 学 task policy，在 outer loop 用 meta-policy 自动调 reward 权重。再加一层 motion augmentation，把同一任务下的物体位姿扰动和交互变化提前灌进训练分布。
- **对比方法/Baselines**: [[InterMimic]]、[[ASAP]]、[[PPO]]、[[SAC]]
- **借鉴意义**: 如果你关心 humanoid 真实交互，这篇是今天最该读的，因为它不只是“稳稳走路”，而是正经把 interaction disturbance 和 reward balancing 当一等公民。
- **锐评**: 这篇最值钱的是方向终于对了，HOI 不再被切成上肢小模块。问题也很明显，任务还是 box-picking / box-pushing 这类相对规整场景，离开放世界交互还早。🔥

### 2. MetaWorld-X: Hierarchical World Modeling via VLM-Orchestrated Experts for Humanoid Loco-Manipulation
- **作者**: Yutong Shen 等
- **机构**: University of Hamburg / 北京工业大学 / 复旦大学 / University of Alberta
- **链接**: [arXiv](http://arxiv.org/abs/2603.08572v1) | [PDF](https://arxiv.org/pdf/2603.08572v1)
- **来源**: 📄 arXiv 关键词检索
- **核心方法**: 用 Skill Expert Pool 先学基础技能，再让 VLM 驱动的 Intelligent Router Module 组合专家，去做 loco-manipulation。思路是把 monolithic policy 的梯度互相打架问题拆掉。
- **对比方法/Baselines**: [[DreamerV3]]、[[PPO]]、[[SAC]]、[[TD-MPC2]]
- **借鉴意义**: 对 whole-body control 和 skill composition 都有参考价值，特别是“语义路由专家策略”这个想法。
- **锐评**: 结构设计很有想象力，但目前更像一个很会讲故事的系统集成方案；VLM router 真带来多少不可替代收益，还得看更硬的 ablation。👀

### 3. Omnidirectional Humanoid Locomotion on Stairs via Unsafe Stepping Penalty and Sparse LiDAR Elevation Mapping
- **链接**: [arXiv](http://arxiv.org/abs/2603.07928v1) | [PDF](https://arxiv.org/pdf/2603.07928v1)
- **来源**: 📄 arXiv 关键词检索
- **核心方法**: 用 sparse LiDAR elevation mapping 解决楼梯感知，再通过 unsafe stepping penalty 压错误落脚。
- **借鉴意义**: 对真正要把 humanoid 从平地拉到复杂地形的人，这种“能落真机场景”的 locomotion 比纯 benchmark 漂亮数值更值钱。
- **锐评**: 方向实用，叙事不花。缺点是方法比较 task-specific，泛化到更杂的 terrain 还得继续补。👀

### 4. Embedding Classical Balance Control Principles in Reinforcement Learning for Humanoid Recovery
- **链接**: [arXiv](http://arxiv.org/abs/2603.08619v1) | [PDF](https://arxiv.org/pdf/2603.08619v1)
- **来源**: 📄 arXiv 关键词检索
- **核心方法**: 把 capture point、CoM state、centroidal momentum 这些经典 balance metric 作为 privileged critic 输入和 shaping reward。
- **借鉴意义**: 这类 work 最大价值不是新潮，而是提醒大家 classical control 不是历史包袱，是能救 RL 的。
- **锐评**: 很朴素，但这种朴素通常比端到端玄学更能上真机。问题是 novelty 没那么炸裂，更像把该做的终于做了。👀

### 5. Towards Human-Like Manipulation through RL-Augmented Teleoperation and Mixture-of-Dexterous-Experts VLA

- **来源**: 📄 arXiv 关键词检索

### 8. Multifingered force-aware control for humanoid robots
- **链接**: [arXiv](http://arxiv.org/abs/2603.08142v1) | [PDF](https://arxiv.org/pdf/2603.08142v1)
- **来源**: 📄 arXiv 关键词检索
