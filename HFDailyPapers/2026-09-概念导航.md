# 本次 HF 阅读的概念导航

解释日期：2026-09-07。不推断用户掌握程度。

- [[PaperNotes/_concepts/11-深度学习基础/On-Policy Distillation|On-Policy Distillation]]：学生先采样，教师在学生访问的前缀上给密集监督；本篇进一步考察监督或数据如何起作用。
- [[PaperNotes/_concepts/11-深度学习基础/Agent Harness|Agent Harness]]：框架组织工具、上下文、控制与验证，模型权重之外的这些程序也影响最终能力。
- [[PaperNotes/_concepts/11-深度学习基础/LoRA|LoRA]]：用低秩矩阵表示权重增量，以少量训练参数适配任务；本篇改变的是适配机制或使用场景。
- [[PaperNotes/_concepts/2-强化学习/World Model|World Model]]：预测动作条件下的状态或观察；可生成视频不自动意味着具备完整动力学。
- [[PaperNotes/_concepts/3-机器人策略/World Action Model|World Action Model]]：联合利用未来环境动态与动作，本文进一步用分阶段数据和快慢分支处理泛化与延迟。
- [[PaperNotes/_concepts/11-深度学习基础/Vision-Language Model|Vision-Language Model]]：VLM 连接图像与语言，但观察理解、执行动作和验证结果仍是不同能力。
- [[PaperNotes/_concepts/11-深度学习基础/Residual Quantization|Residual Quantization]]：多个码本逐级编码残差，以短 token 序列表示较细的连续动作结构。
- [[PaperNotes/_concepts/11-深度学习基础/KL Divergence|KL Divergence]]：KL 衡量非对称分布差异；训练、正则与蒸馏中的方向和权重需要分别说明。
- [[PaperNotes/_concepts/1-生成模型/Flow Matching|Flow Matching]]：学习把噪声送到数据的速度场，可生成图像、视频或动作；少步推理通常需额外蒸馏。
- [[PaperNotes/_concepts/11-深度学习基础/Chain-of-Thought Prompting|Chain-of-Thought Prompting]]：思维链保存中间步骤，但可见文本不保证完整反映因果推理，也可能含冗余。
- [[PaperNotes/_concepts/3-机器人策略/Action Chunking|Action Chunking]]：动作块可降低决策频率，但接触反馈、时序与执行速度仍需单独验证。
- [[PaperNotes/_concepts/11-深度学习基础/Retrieval-Augmented Generation|Retrieval-Augmented Generation]]：先检索证据再回答；检索、表示压缩与读出推理是不同环节，不能混为同一能力。
