## Humanoid / Teleoperation / Whole-Body

### 1. Morphology-Consistent Humanoid Interaction through Robot-Centric Video Synthesis
- **作者**: Weisheng Xu 等
- **机构**: HKUST(GZ), 哈工大深圳, 深圳大学, University of Cambridge
- **链接**: [arXiv](https://arxiv.org/abs/2603.19709v1) | [PDF](https://arxiv.org/pdf/2603.19709v1)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[Dream2Act]]

![](https://arxiv.org/html/2603.19709v1/figs/fig1.png)

- **核心方法**: 这篇的输入不是人类骨架，而是机器人的第三人称图像和目标物体。作者先用视频生成模型在机器人自身形态上合成“它完成任务之后应该长什么样”，再从这些 robot-centric dreams 里恢复机器人原生的关节轨迹，最后交给 [[Whole-Body Controller]] 执行。关键区别在于它不再把人类姿态估计和 [[SMPL]] retargeting 当成中间桥，而是直接在机器人几何和 [[URDF]] 约束里做 whole-body motion recovery。输出因此不是一个还要再映射一次的人类动作，而是更接近可执行的机器人轨迹。
- **对比方法/Baselines**: 主要对着 human-centric pose estimation + retargeting 管线，尤其是先拟合 [[SMPL]] 再映射到 humanoid 的老路子。它借鉴了 native pose extraction 和运动学恢复，但核心不是“估计得更准”，而是彻底绕开 morphology gap。
- **借鉴意义**: 对 humanoid imitation、whole-body interaction、robot-centric motion generation 都很有启发。你如果关心 cross-embodiment / whole-body teleoperation，这篇至少给出了一条不靠人类骨架中转的路线。
- **锐评**: 这篇最值钱的地方，是它终于承认“retargeting 失败”不是姿态估计器不够强，而是中间表示本身就站错了坐标系。问题也很直接，四个任务总成功率只有 37.5%，离稳定 deployment 还差得远；但 baseline 是 0%，它至少证明这条路不是幻觉。今天真有必要精读的就是它。🔥
- **关联笔记**: [[SMPL]] — 这篇本质上是在批评 human-centric skeletal fitting 作为 robot interaction 中间层的先天缺陷。

### 2. KUKAloha: A General, Low-Cost, and Shared-Control based Teleoperation Framework for Construction Robot Arm
- **作者**: Yifan Xu 等
- **机构**: University of Michigan
- **链接**: [arXiv](https://arxiv.org/abs/2603.20129v1) | [PDF](https://arxiv.org/pdf/2603.20129v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.20129v1/figure/RelatedWork.png)

- **核心方法**: KUKAloha 把 teleoperation 拆成两半来做。输入侧用一个轻量 leader arm 负责粗粒度的人类引导，精对齐和抓取则交给基于 AprilTag 的自动对准模块做；输出不是炫技 demo，而是一套可复用的 shared-control teleop stack。它的重点不是学出一个 policy，而是把“人做大动作，系统做精对齐”这件事拆清楚，降低大机械臂示教和操作的门槛。
- **对比方法/Baselines**: 直接对着 teach pendant、3D mouse 和 VR/AR teleoperation 这些传统入口。它不是说自己最沉浸，而是说自己更便宜、更稳、更适合大机械臂演示收集。
- **借鉴意义**: 对 teleoperation data collection、shared autonomy、以及大臂粗到细的控制分层很有现实意义。你要是正在想怎么快速堆 demonstration，这种系统工作比再加一个 fancy policy 更实用。
- **锐评**: 这工作一点都不性感，但很有用。它真正解决的是“怎么把人拉进回路又不让人把精细操作搞崩”这个现实问题。硬伤也很明显: 一旦感知前提没那么干净，或者任务不再是 tag-assisted 对齐抓取，这套 shared-control 增益还能不能保住，就没那么确定了。👀
- **关联笔记**: [[URDF]] — 虽然这篇不是建模论文，但它同样受益于把 robot geometry 和 control hierarchy 说清楚。
- 💡 **想精读？** 运行：`读一下 KUKAloha: A General, Low-Cost, and Shared-Control based Teleoperation Framework for Construction Robot Arm`

### 3. AGILE: A Comprehensive Workflow for Humanoid Loco-Manipulation Learning
- **作者**: Huihua Zhao 等
- **机构**: NVIDIA
- **链接**: [arXiv](https://arxiv.org/abs/2603.20147v1) | [PDF](https://arxiv.org/pdf/2603.20147v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.20147v1/x1.png)

- **核心方法**: AGILE 不是再发一个“我们又把 humanoid RL 训通了”的成绩单，而是把环境核验、可复现训练、统一评测、描述符驱动部署四个环节串成一个完整 workflow。输入是 robot/task descriptors、仿真环境和训练配置，系统在中间插入 motion-quality diagnostics、regression testing 和一些训练稳定化技巧，输出是更可控的 loco-manipulation policy 开发流程。它和常见 humanoid 框架最大的区别，不在于某个 loss 多聪明，而在于它把 sim-to-real 的脆弱环节放到流水线里逐项检查。
- **对比方法/Baselines**: 主要对着那些只覆盖训练或只覆盖部署的 humanoid RL 框架。它吸收了 [[Reinforcement Learning]] 社区已有的训练 tricks，但卖点是端到端工程闭环，不是单个算法组件。
- **借鉴意义**: 对 humanoid loco-manipulation、实验可复现、以及大规模策略回归测试非常有参考价值。你如果已经厌烦“这次能跑，下次环境一改就炸”，AGILE 这种工作比再堆一层模型更接近真正生产力。
- **锐评**: 这篇的价值很朴素: 它在补系统工程的黑洞，而这个黑洞恰好是 humanoid 最容易被论文忽悠过去的地方。问题是它本质上更像 workflow / infra 论文，很多收益也强依赖作者掌控的工具链和工程纪律。想直接把它当成一种新 control 方法，那就是搞错了。👀
- **关联笔记**: [[Reinforcement Learning]] — AGILE 真正想解决的不是 RL 算法缺失，而是 RL 生命周期管理失控。
- 💡 **想精读？** 运行：`读一下 AGILE: A Comprehensive Workflow for Humanoid Loco-Manipulation Learning`

### 4. F1: A Vision-Language-Action Model Bridging Understanding and Generation to Actions
- **作者**: Qi Lv 等
- **机构**: 上海 AI Lab, 哈工大深圳
- **链接**: [arXiv](https://arxiv.org/abs/2509.06951) | [PDF](https://arxiv.org/pdf/2509.06951)
- **来源**: 🔥 HF Trending，⬆️ 33

- **核心方法**: F1 想做的是把 visual foresight 正式塞回 [[Vision-Language-Action]] 的决策链路。输入是语言、当前观测和任务上下文，模型先生成 goal-conditioned 的未来视觉目标，再把 action generation 改写成“朝这个未来状态反推动作”的问题，而不是只做 reactive state-to-action mapping。架构上它把 perception、foresight generation 和 control 分给不同 transformer 分支，再用三阶段训练把这些分支绑到一起。和普通 VLA 不同，它不是多挂一个图像头装规划，而是试图让未来视觉成为真正的中间控制目标。
- **对比方法/Baselines**: 主要对比现有 reactive VLA 路线，以及不显式建模 foresight 的 action policy。它也借了 [[VQ-VAE]] 一类生成组件，但核心变化是把 generation 变成控制中间层。
- **借鉴意义**: 对 long-horizon action planning、dynamic scene robustness、以及“生成模型到底怎么服务控制”这件事都有参考价值。尤其如果你对世界模型和 VLA 之间的接口一直不满意，这篇至少在认真答这个问题。
- **锐评**: 这工作比很多 VLA 大词论文强的一点，是它真的在摸 action 之前先构一个未来目标，而不是把 planning 两个字写在标题里就算交差。可它的毛病也没消失: 依旧是一篇大一统路线论文，真正最难的接触细节、形态差异和 whole-body 执行问题，并没有因为多了 foresight 就自动解决。👀
- **关联笔记**: [[Vision-Language-Action]] — F1 的核心贡献不在新的 action head，而在于把 foresight 强行塞进 VLA 的中间层。
- 💡 **想精读？** 运行：`读一下 F1: A Vision-Language-Action Model Bridging Understanding and Generation to Actions`

### 5. ViTac-Tracing: Visual-Tactile Imitation Learning of Deformable Object Tracing
- **作者**: Yongqiang Zhao 等
- **机构**: King's College London, Imperial College London
- **链接**: [arXiv](https://arxiv.org/abs/2603.18784v1) | [PDF](https://arxiv.org/pdf/2603.18784v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.18784v1/x1.png)

- **核心方法**: 这篇把 deformable tracing 拆成 local contact 和 global task progression 两层。输入是视觉和触觉观测，局部上用 weighted loss 强化“保持触觉接触在中心区域”的微调行为，全局上再加 tracing task loss 约束任务推进，输出是一个统一处理 1D/2D deformable tracing 的 imitation policy。它还配了一套低成本 teleoperation system，把 tactile 信息不是当彩蛋，而是当任务是否持续成功的关键输入。
- **对比方法/Baselines**: 主要对着 object-specific deformable modeling、只靠 sim-to-real transfer 的 tracing 路线，以及视觉单模态 imitation baseline。它没有假装“多一块触觉就一定赢”，而是明确用局部和全局损失去解释增益来源。
- **借鉴意义**: 对 contact-rich manipulation、visuo-tactile imitation、以及 teleop-driven data collection 很有价值。哪怕你不做 deformable，这种“局部接触 + 全局进度”拆分也能借到更多 manipulation 任务里。
- **锐评**: 这篇最靠谱的地方，是它知道 tracing 难点不只是“看见绳子”，而是持续贴着对象走而不掉。问题同样很清楚: tracing 终究还是 tracing，离更复杂的 whole-body 或多接触序列 manipulation 还差一段。它是个干净扎实的中层工作，不是通用解。👀
- **关联笔记**: [[ACT]] — 这篇虽然不是 action chunking 本身，但同样在用时序动作建模去维持接触稳定性。
- 💡 **想精读？** 运行：`读一下 ViTac-Tracing: Visual-Tactile Imitation Learning of Deformable Object Tracing`

### 6. Speculative Policy Orchestration: A Latency-Resilient Framework for Cloud-Robotic Manipulation
- **作者**: Chanh Nguyen 等
- **机构**: Umeå University, KTH
- **链接**: [arXiv](https://arxiv.org/abs/2603.19418v1) | [PDF](https://arxiv.org/pdf/2603.19418v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.19418v1/x1.png)

- **核心方法**: SPO 的输入是云端 world model 预测出的未来运动学 waypoint 和当前执行误差。它在云端提前生成一串将来的动作候选，边缘端只负责缓存、验证和截断，再用 adaptive horizon scaling 根据实时误差调节预取深度。为防止 speculative execution 把机器人带进沟里，作者又在边缘端加了一个 $\\epsilon$-tube verifier 去约束轨迹偏差。和 blocking remote inference 或静态缓存比，它的差异是把 latency 视作系统结构问题，而不是网络坏一点就认命。
- **对比方法/Baselines**: 主要对比 blocking remote inference 和 static caching 一类 cloud control baseline。它借用 world model 预判未来，但真正的贡献是 orchestration 和 runtime verification。
- **借鉴意义**: 对 cloud robotics、远程 manipulation、以及 network-constrained control 很有参考价值。你如果碰过远端推理一抖就 command starvation 的烂问题，这篇就是在修这个。
- **锐评**: 这篇的优点是特别老实，知道云端控制最大的问题不是“模型够不够大”，而是 RTT 一来整条控制链就开始抽风。问题是它再会 orchestrate，也救不了一个漂得太厉害的 world model；预测错得离谱时，verification 只会更频繁地把你打回保守模式。👀
- **关联笔记**: [[Model Predictive Control]] — 它不是经典 MPC，但同样是在用有限预测窗口给实时控制争取喘息空间。
- 💡 **想精读？** 运行：`读一下 Speculative Policy Orchestration: A Latency-Resilient Framework for Cloud-Robotic Manipulation`

### 7. CeRLP: A Cross-embodiment Robot Local Planning Framework for Visual Navigation
- **作者**: Haoyu Xi 等
- **机构**: 上海交通大学, 东方理工
- **链接**: [arXiv](https://arxiv.org/abs/2603.19602v1) | [PDF](https://arxiv.org/pdf/2603.19602v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.19602v1/x1.png)

- **核心方法**: CeRLP 想解决的不是“再收更多 heterogeneous robot data”，而是把不同机器人和不同相机看到的视觉输入先压到一个统一几何形式里。输入是 monocular depth 或其它视觉观测，作者先用 offline pre-calibration 和 online scale correction 把 metric depth 校回来，再把视觉信号抽成 height-adaptive laser scan，最后交给 local planner 做避障和导航。核心差异是它把 embodiment gap 当几何问题处理，而不是继续靠 per-robot fine-tuning 硬补。
- **对比方法/Baselines**: 主要对着大规模多机器人数据收集路线，以及每换一种 robot / camera 就单独 fine-tune 的套路。它也参考了视觉导航和局部规划基线，但亮点是 visual-to-scan abstraction。
- **借鉴意义**: 对 cross-embodiment planning、heterogeneous sensor abstraction、以及 geometry-aware transfer 都有启发。虽然主战场是 navigation，但思路对不同 embodiment 之间的表征统一也很值钱。
- **锐评**: 这篇的优点是脑子很清楚，知道 embodiment mismatch 不是全都要用 foundation model 糊过去，很多时候几何抽象先做对就能省一大半麻烦。问题同样明显: 它是 local planner，不是 whole-body interaction policy；你要拿它回答 humanoid manipulation，肯定答不全。👀
- **关联笔记**: [[Model Predictive Control]] — 不是同一类方法，但都在强调几何约束和执行可行性不能在控制前被抹平。
- 💡 **想精读？** 运行：`读一下 CeRLP: A Cross-embodiment Robot Local Planning Framework for Visual Navigation`

### 8. Not All Features Are Created Equal: A Mechanistic Study of Vision-Language-Action Models
- **作者**: Bryce Grant 等
- **机构**: Case Western Reserve University
- **链接**: [arXiv](https://arxiv.org/abs/2603.19233v1) | [PDF](https://arxiv.org/pdf/2603.19233v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2603.19233v1/figures/fig1_core_findings.png)

- **核心方法**: 这篇不是造新 VLA，而是把现有 VLA 拆开验尸。输入是六种不同架构的 rollout activation，作者用 activation injection、linear probe 和 sparse autoencoder 去分析视觉通路、语言通路和 action expert 到底各管什么，输出是一堆很直白的结论: 视觉表征往往主导动作，语言只在多目标歧义场景里真正关键，motor program 更多待在 expert pathway 里。它和常见 interpretability paper 的差别，是它直接对机器人行为做因果干预，而不是只看 attention 热图自我感动。
- **对比方法/Baselines**: 覆盖 [[OpenVLA]]、SmolVLA、GR00T 这一类不同设计的 VLA family。不是在比新 benchmark，而是在比这些路径到底谁在干活。
- **借鉴意义**: 对 VLA 调试、失败分析、以及为什么“改 prompt 没啥用”这类现象都有直接帮助。你如果在做 embodied foundation model，这种 mechanistic work 比再涨一点 success rate 更能解释问题出在哪。
- **锐评**: 它最有价值的地方是把 VLA 的黑箱拆成了几个还能讨论的部件，不再让“多模态很复杂”成为偷懒借口。缺点也很明显: 它解释的是现象，不是解决方案；你看完会更清楚模型为什么犯蠢，但不会自动得到一个不犯蠢的新模型。👀
- **关联笔记**: [[OpenVLA]] — 这篇最值得借的不是结果本身，而是它分析 OpenVLA 这类模型时的因果介入思路。
- 💡 **想精读？** 运行：`读一下 Not All Features Are Created Equal: A Mechanistic Study of Vision-Language-Action Models`

- `WorldCam`：3D gaming world 很热闹，但和真实机器人控制闭环隔得太远。
- `IndoorR2X`：IoT + LLM 多机器人协调有意思，但更像 semantic planner benchmark，不是你现在最缺的 embodied control。
- `The Robot's Inner Critic`、`Not an Obstacle for Dog, but a Hazard for Human`：各自问题设定都成立，但偏 social behavior / assistive navigation 支线，不是今天该优先精读的主菜。
- `A Closed-Form CLF-CBF Controller for Whole-Body Continuum Soft Robot Collision Avoidance`、`Generalized Task-Driven Design of Soft Robots`、`SOFTMAP`：soft robot 线有硬活，但和 humanoid / teleop / loco-manipulation 主线耦合度不够。
- `Generation Models Know Space`、`MonoArt`：表征和 3D 理解做得不差，但离直接可执行机器人策略还隔着一层接口问题。
- `PA2D-MORL`、`Unlabeled Multi-Robot Motion Planning`、`Can LLMs Prove Robotic Path Planning Optimality?`：更多是算法/理论侧增量，不是今天最值钱的机器人系统缺口。

## 收尾

今天真正该盯的是 `Dream2Act` 这条线，因为它终于把 humanoid interaction 里最恶心的 morphology gap 当成主问题处理，而不是继续给 retargeting 打补丁。第二梯队里，`KUKAloha`、`AGILE` 和 `SPO` 都在补你迟早要碰的工程债；`F1`、`CeRLP` 和那篇 VLA mechanistic study 则是在回答“表征和控制到底怎么接”这类更长期的问题。今天不是 headline 满天飞的一天，但地基味很重，这种日子反而更值钱。
