# WholeBodyVLA

`WholeBodyVLA` 是一类把视觉语言输入直接映射到 humanoid whole-body 行为的策略路线。

## 为什么重要

- 它代表了当前很多 humanoid visual control 的主流方向。
- 优点是端到端，缺点通常是很吃 embodiment-specific 数据。
- [[ZeroWBC]] 的价值之一，就是给这条路线提供了更便宜的人类数据替代方案。
