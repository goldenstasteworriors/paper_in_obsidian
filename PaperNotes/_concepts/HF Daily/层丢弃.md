# 层丢弃

训练时随机绕过整个网络层，又称随机深度。它改变的是实际执行的深度，不只是把层内某些神经元置零；推理时能否安全跳层仍需验证。

- [Don't Drop Dropout: Optimizing Layer Sparsity for Efficient LLM Training and Inference](https://arxiv.org/abs/2609.05275)
