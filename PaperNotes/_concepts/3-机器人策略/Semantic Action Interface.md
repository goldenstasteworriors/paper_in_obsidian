# Semantic Action Interface

## 定义

让决策模型在具有明确含义的小规模动作集合中选择，由形态专用解释器映射到实际控制的接口。

## 数学形式

$$
a_t\in\mathcal A,\qquad u_t=g_E(a_t;s_t).
$$

a为语义动作，A为词表，E为形态，s为内部目标状态，u为低层控制。动作名称、公制步长和参考坐标必须分别说明。

## 核心要点

1. 语义可读不等于物理约定自动明确，前后左右必须有参照。
2. 共享动作词表不保证共享控制器，也不自动实现未见形态泛化。
3. 离散步长可在部署时修改，但速度、接触与闭环观测条件限制其适用范围。
