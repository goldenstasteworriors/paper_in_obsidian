# Vision-Language Model

`Vision-Language Model` 指同时处理视觉输入和文本输入的多模态模型，常见缩写是 `VLM`。

## 为什么重要

- 能把图像中的空间语义和文本指令对齐。
- 在机器人里常被拿来做 perception、planning、action token generation。
- 对 [[ZeroWBC]]，它负责把第一视角图像和语言指令映射成未来动作 token。
