## 本月目前最值得记住的五条线索

### 1. 自我改进开始拆分成知识、执行框架、权重和外部验证

[Repo-To-Skill](https://arxiv.org/html/2609.02749) 在固定底座和执行框架时加入经过验证的操作知识，报告显著增益；[WHALE](https://arxiv.org/html/2609.00196) 则说明权重和框架可能互为瓶颈，交替优化比只动一端更有效。但技能构建有额外成本，最好检查点的收益也不等于持续稳定进步。

另一组论文给出必要的边界：[HarnessDev](https://arxiv.org/html/2609.01437) 发现自动框架的收益对执行模型敏感；[ASPIRE](https://arxiv.org/html/2608.31111) 发现模糊目标下选错数据、自测过窄和后续退化；[S3Gym](https://arxiv.org/html/2608.31100) 显示总结记忆有时不如原始历史。

**我的判断：值得研究的是如何让经验在外部隐藏任务上产生可复用收益。** 做完训练、写出框架、自测得分上涨都应单独记账，不能合并成“自主进化成功”。

### 2. 世界模型从视觉质量走向可控状态、长期记忆和物理证据

[SolarWM](https://arxiv.org/html/2609.02886) 重点开放数据合同与跨底座训练；[H3-World](https://arxiv.org/html/2609.01560) 将语言动作按时间绑定；[Matrix-Game 3.5](https://arxiv.org/abs/2608.29910) 通过几何 patch 记忆改善回访；[Puffin-World](https://arxiv.org/html/2609.04196) 将方向线索、深度与外观显式纳入统一状态。它们优化的对象不同，不宜只按最长演示时长排序。

评价也在细化：[WorldReward](https://arxiv.org/abs/2609.03952) 同时评价动作执行与视觉偏好；[Principia](https://arxiv.org/abs/2609.04200) 检验成对物体的相对物理关系；[VeriPhy](https://arxiv.org/abs/2609.03153) 追溯每项判定的工具证据并允许未知。

**我的判断：能持续生成、能听相机指令、物理关系正确、能帮助机器人规划，应视为四个独立目标。** Principia 所报 VBench 约 0.8 而物理分数不超过 0.42，是最直观的提醒；这些分数不在同一刻度，不能直接相减。

### 3. 人类视频到机器人控制，出现三种清楚的切入方式

- **扩大训练经验**：[ZimaBlue](https://arxiv.org/html/2609.00188) 用人类视频预训，再动作中训和目标机器人后训；快慢分支处理延迟。
- **找对示范**：[RoboTok](https://arxiv.org/html/2609.03199) 用规范化三维手部轨迹检索相关操作，将检索结果用于仿真 PPO 奖励。
- **搭建可编辑环境**：[Lucida](https://arxiv.org/html/2608.30821) 从真实观测解析物体，补完整资产，再用 VLM 多轮摆放对齐。

这些工作能组成值得探索的研究链路，但**本次阅读没有发现它们已经被组合成同一个、验证过的端到端系统**。视频动态先验、示范运动相似性和仿真几何恢复之间，仍缺接触、物理参数和真机迁移证据。

### 4. OPD 的收益来源与“数据量”口径都受到挑战

[OPSA](https://arxiv.org/html/2608.31046) 发现所测 OPD 收益可由压低学生尾部 token 的无教师训练得到；[One-shot OPD](https://arxiv.org/html/2609.04172) 则报告一题反复采样也能提供很广的状态覆盖，16 个多样 query 可接近全数据。

与此同时，[IDA-OPD](https://arxiv.org/abs/2608.29846) 关注蒸馏后多样性不够，[RLVR 入口收缩研究](https://arxiv.org/abs/2608.29188) 将解法丢失定位到最早的分支选择。这些论文的底座、损失与评价范围不同。

**我的判断：接下来应同时量化 query 数、rollout 数、监督状态覆盖、教师计算、更新步数及 pass@k。** “一题”不等于一次学习，“教师可去掉”的特定结果也不等于教师知识普遍无效。

### 5. 效率研究越来越重视朴素基线与严格预算对照

[Random Attention](https://arxiv.org/html/2609.03430) 表明，保护完整输入后，随机保留推理 KV 就能接近复杂打分器；[Declarative Attention](https://arxiv.org/html/2609.02737) 让模型主动声明读取范围；[LatentPress](https://arxiv.org/html/2609.01507) 用连续记忆压缩，但主要记忆实验预先提供了正确证据。[SMELT](https://arxiv.org/html/2609.01343) 同时匹配计算、参数与缓存，再检验重复中间层的作用。

**我的判断：节省的是 FLOPs、注意力读取量、存储、token 还是墙钟时间，必须写清楚。** 压缩更强可能改变答案长度，少 token 可能增加解码循环，理论优势不自动变成端到端收益。

## 一个可继续讨论的研究问题

**如何区分人类示范中跨机器人可迁移的“接触与任务阶段”，和不应直接照搬的“运动时序与几何轨迹”？**

RoboTok 的 DTW 使检索容忍局部速度差异，但 ParcelStow 提醒速度变化会暴露接触失败；ZimaBlue 则将不同机器人放进共享语义动作空间。一个合理的研究假设是：动作检索应同时保留阶段/接触语义与速度条件，评测时分开看标准速度、演示覆盖速度和域外速度。**这是由几篇论文引出的个人推断，尚不是本文已完成的新颖性检索或已证明方案。**
